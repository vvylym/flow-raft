## Documentation Principles

1. **Up-to-date**: All documentation reflects current implementation
2. **Concise**: Focus on essential information, avoid verbosity
3. **Practical**: Include code examples and real-world usage
4. **Accurate**: Cross-referenced with actual codebase

## Contributing to Documentation

When updating documentation:

1. Keep it concise and focused
2. Update related documents when making changes
3. Include code examples where helpful
4. Remove outdated information promptly
5. Cross-reference related documents
